## 🚀 Installation & Setup

### **Prerequisites**
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Git (optional, for cloning)
- Local server or live server extension (for local development)

### **Quick Start**

1. **Clone the repository:**
   ```bash
   git clone https://github.com/samdev969/portfolio.git
   cd portfolio
   ```

2. **Open in browser:**
   - Double-click `index.html` to open directly, OR
   - Use VS Code Live Server:
     - Install Live Server extension
     - Right-click `index.html` → "Open with Live Server"
   - Or use Python's built-in server:
     ```bash
     python -m http.server 8000
     # Then visit http://localhost:8000
     ```

3. **Customize:**
   - Update contact information in `index.html`
   - Modify styles in `css/style.css`
   - Edit JavaScript logic in `js/app.js`

### **Dark Mode Implementation**
The site includes an automatic dark mode toggle. The theme preference is stored and persists across sessions.
